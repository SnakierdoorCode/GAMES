# READ ME!
**Please read this to understand what this repository is for.**

### About This Repository
The games hosted here are for **[The Universal Stash](https://snakierdoorcode.github.io/TheUniversalStashSite/)**. 

The goal of this site isn't to bypass school blockers, it’s simply to give students something fun to do when they finish their classwork early and have extra free time to kill.

### Copyright & Game Removal (DMCA)
If you are a game developer and do not want your game featured on the site, please reach out to me on **[Discord](https://discord.gg/2PYsv2Cgz7)**. Let me know which game is yours, and I will gladly remove it right away!
